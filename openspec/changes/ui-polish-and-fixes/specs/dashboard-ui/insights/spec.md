## Purpose
Ensures that visual charts in the dashboard are accompanied by contextual educational insights teaching the user how to interpret the data.

## ADDED Requirements

### Requirement: Active Landscape Insights
The dashboard SHALL display a contextual "💡 Insights" expander or tooltip directly associated with the Current Active Landscape chart to teach users how to read their application health.

#### Scenario: User views the Active Landscape chart
- **WHEN** the user views the Current Active Landscape section
- **THEN** an educational insight is visible explaining how to interpret the distribution of application statuses (e.g., what it means to have many 'Applied' vs 'Interviewing').
